Этот навык (Skill) описывает стандарты разработки, типовые сценарии и рабочие регламенты для работы с кодовой базой **Spectool**.

## 2. Рабочий регламент: Геометрия и CAD-холст (`Canvas.tsx`)

### Принципы черчения:
1. **Режимы работы:**
   - Клавиша `L` — Режим **«Чертить»**: клик ставит первую точку, следующий клик завершает отрезок. Автоматически привязывается к существующим узлам и линиям.
   - Клавиша `V` — Режим **«Выбор»**: позволяет кликать на линии для назначения профилей, перетаскивать вершины и выбирать ячейки.
   - Клавиша `O` — Переключатель **ORTHO**: фиксирует черчение строго по горизонтали ($dx$) или вертикали ($dy$).
   - Клавиша `Delete` / `Backspace` — Удаление выбранного элемента.
2. **Координаты:**
   - Все координаты хранятся в миллиметрах реального масштаба фасада.
   - Начало координат $(0, 0)$ находится в нижнем левом углу базового габарита модуля.

## 3. Рабочий регламент: Алгоритм детекции проёмов (`cellDetector.ts`)

Алгоритм выполняет поиск замкнутых прямоугольных областей:
1. Извлекает все уникальные X-координаты вертикальных профилей и Y-координаты горизонтальных профилей.
2. Для каждого потенциального прямоугольника $[x_1, x_2] \times [y_1, y_2]$:
   - Проверяет покрытие всех 4 сторон существующими отрезками профилей с учётом допустимого допуска (допуск 2 мм).
   - Проверяет отсутствие внутренних секущих стоек или ригелей, делящих проём пополам.
3. Сохраняет найденные ячейки в `module.cells` с автоматическим расчётом габаритов $W$ и $H$.

## 4. Рабочий регламент: Базы данных метизов и материалов (`databaseService.ts`)

### Структура файла «Метизы.xlsx»:
- Колонки: `Обозначение | Наименование | Тип | Стандарт | Основной диаметр | Длина | Материал и/или покрытие | Класс прочности | Цвет | Артикул`.
- Столбец **«Тип»** автоматически группирует метизы по папкам/категориям.
- По умолчанию встроено **338 заводских позиций**.

### Структура файла «Материалы.xlsx»:
- Рекомендуемые колонки: `Раздел | Подраздел | Артикул | Наименование | Материал / Сплав | Ед. изм. | Вес | Габариты`.
- Либо колонка `Путь` вида `Профили / Alutech / Стойки`.
- Автоматически строит двухуровневое раскрывающееся дерево папок.

### Персистентность (LocalStorage):
- Ключи хранилища: `spectool_hardware_items_v2` и `spectool_materials_items_v2`.
- При выборе пользователем своего Excel-файла данные сохраняются навсегда и мгновенно восстанавливаются при последующих запусках.

## 5. Рабочий регламент: BOM-движок спецификаций (`bomEngine.ts`)

1. **Соответствие форме А1187 М507 («Модуль Жукова»):**
   - 19 колонок (A–S): Марка, Наименование, Материал (обозначение, наименование, кол-во, ЕИ), Шаблон техпроцесса, Тип связи, Количество в спецификации, ЕИ, VGB-параметры (L, B, LB, Color, углы подрезки VGP).
2. **Стилизация Excel:**
   - Детали: заливка `#E2EFDA` (мягкий зелёный).
   - Комплектующие и крепеж: заливка `#D9E1F2` (мягкий синий).
   - Живые формулы Excel для расчета длин, площадей и весов.

## 6. Регламент сборки и запуска (Gotchas & Commands)

> [!CAUTION]
> **ELECTRON_RUN_AS_NODE**: В окружении терминалов IDE переменная `ELECTRON_RUN_AS_NODE=1` может заблокировать запуск окон Electron. Всегда очищайте её перед сборкой или запуском!

### Основные команды:
```bash
# 1. Запуск веб-сервера разработки
npm run dev

# 2. Компиляция фронтенда
npm run build

# 3. Сборка автономного portable Spectool.exe
cmd /c "set ELECTRON_RUN_AS_NODE=& npx.cmd electron-builder --win portable"

# 4. Загрузка собранного релиза на GitHub
cmd /c "gh release upload v1.0.0 release\Spectool.exe --clobber"
```
Результат сборки: `release/Spectool.exe` (~109 МБ, полностью портативный, работает без Node.js на любом ПК с Windows x64).
