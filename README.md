# Spectool — Интерактивный CAD-конструктор модульных фасадов и спецификаций

Инженерная BIM/CAD-утилита для интерактивного проектирования навесных светопрозрачных и глухих модулей, привязки профилей, комплектующих и метизов, автоматического расчёта спецификаций (BOM) и выгрузки в Excel 1-в-1 по заводскому эталону («Модуль Жукова»).

---

## 🚀 Как запустить на другом компьютере

### Способ 1: Для разработки / запуска через Node.js (Рекомендуемый)
1. Установите [Node.js](https://nodejs.org/) (LTS версия).
2. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com/pururuall/Spectool.git
   cd Spectool
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите:
   - Через батник: двойной клик по `Запуск_Spectool.bat`
   - Или через терминал: `npm run dev`
   - Приложение откроется в браузере по адресу `http://localhost:3000`.

### Способ 2: Запуск без установки Node.js (Автономная работа)
Сборка проекта (`npm run build`) компилирует всё приложение в папку `dist/`.
Для запуска готовой сборки на любом компьютере достаточно:
- Запустить любой локальный статический сервер (например, расширение Live Server в VS Code, Python `python -m http.server 3000` в папке `dist`, или утилиту типа `serve`).
- Либо можно упаковать приложение в десктопный `.exe` через Electron / Tauri.

## 🛠 Что реализовано в проекте

1. **Интерактивный CAD-холст (`Canvas.tsx`):**
   - Черчение профилей по точкам с шагом привязки к сетке (25 мм) и магнитной привязкой к стойкам и ригелям.
   - Режим **ORTHO** для строго вертикального и горизонтального черчения.
   - Разделение режимов: «Чертить (L)» и «Выбор (V)».
   - Редактирование геометрии перетаскиванием вершин в режиме выбора.
   - Быстрое построение контура модуля кнопкой `+ Контур`.

2. **Автоматическое геометрическое распознавание проёмов (`cellDetector.ts`):**
   - Умный алгоритм, анализирующий пересечения ригелей и стоек любой конфигурации (Т-образные примыкания, сетки 2×2, 3×3, асимметричные поля).
   - Кнопка **«Найти области»** мгновенно находит все замкнутые проёмы и создаёт кликабельные элементы заполнения.

3. **Универсальное управление заполнением проёмов (`ParametersBox.tsx`):**
   - Настройка типа связи (`деталь`, `комплектующие`, `Сборочная единица`).
   - Переключатель «С материалом» / «Без материала» (стеклопакеты, решетки, створки не привязывают лишний листовой металл; короба утепления содержат точный материал и развертку).
   - Быстрые кнопки геометрии: «По осям», «Зазор -25мм», «Развертка короба».
   - Система шаблонов заполнений (Presets) с сохранением в `localStorage` браузера.

4. **Двусторонняя спецификация и BOM-движок (`bomEngine.ts`):**
   - Генерация 19-колоночной производственной ведомости.
   - Расчёт формул подрезки, площадей, шага метизов (`ROUNDUP`, `ROUND`, `CEIL`, `FLOOR`).
   - Выгрузка в Excel (`.xlsx`) с живыми формулами и фирменным цветовым оформлением:
     - Зелёный: строчки деталей (A-S)
     - Синий: строчки комплектующих (A-K).
