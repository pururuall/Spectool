# Spectool — Интерактивный CAD-конструктор модульных фасадов и спецификаций

Специализированная инженерная 2D CAD/BIM-утилита для проектирования навесных светопрозрачных и глухих модулей, привязки профилей, комплектующих и метизов, автоматического расчёта спецификаций (BOM) и выгрузки в Excel 1-в-1 по отраслевому заводскому эталону (**«Модуль Жукова» / А1187 М507**).

## 🛠 Ключевые возможности

### 1. Десктопная лента меню и интерактивный CAD-холст (`MenuBar.tsx`, `Canvas.tsx`)
- **Лента меню (File, Edit, View, Window, Settings):**
  - Быстрый доступ ко всем операциям: Новый проект, Открыть/Импорт, Сохранить `.spectool`, Экспорт Excel, Настройки БД.
  - Управление видимостью панелей (Параметры, Материалы, Метизы, Спецификация).
- **4 режима отображения размеров на чертеже:**
  1. **Интерактивные размеры при выборе (по ТЗ)** (`selection_inputs`): плавающие HTML `<input>` над ригелями и стойками, позволяющие напрямую задавать расстояние до соседних профилей с мгновенным пересчетом геометрии.
  2. **Инженерные размерные цепочки** (`outer_chains`): внешние цепочки размеров AutoCAD/Revit слева (высотные отметки) и снизу (шаг пролётов) с засечками 45° и габаритами $H$ и $L$.
  3. **Размеры на всех линиях** (`all_lines`): бейджи длин над каждым отрезком.
  4. **Скрыть размеры** (`hidden`): чистый геометрический чертёж.
- **Два режима работы холста:**
  - `L` — Режим **«Чертить»**: построение стоек и ригелей по точкам с шагом сетки 25 мм и магнитной привязкой к существующим узлам и линиям.
  - `V` — Режим **«Выбор»**: перетаскивание узлов мышью, выбор линий для назначения профилей и выбор ячеек.
- **Режим ORTHO (`O`):** строгое выравнивание черчения по горизонтали или вертикали.
- **Быстрый контур:** построение внешнего периметра модуля по габаритам $W \times H$ в один клик.
- **Зум и панорамирование:** свободная навигация по фасаду колёсиком мыши и зажатой средней кнопкой.

### 2. Геометрический алгоритм детекции контуров (`cellDetector.ts`)
- Автоматический поиск замкнутых прямоугольных областей (проёмов/полей) в любой сетке профилей (включая Т-образные врезки, импосты и асимметричные деления).
- Кнопка **«Найти области»** мгновенно рассчитывает проёмы и создаёт интерактивные элементы заполнения с точными габаритами $W$ и $H$.

### 3. Универсальные заполнения проёмов (`ParametersBox.tsx`)
- **Типы связи:** `деталь`, `комплектующие`, `Сборочная единица`.
- **Гибкость материалов:**
  - Светопрозрачные заполнения (стеклопакеты, створки, вентрешетки) не подвязывают лишний листовой металл.
  - Глухие зоны (короба утепления, экраны) содержат точный материал и развертку.
- **Быстрые пресеты:** «По осям», «Зазор -25мм», «Развертка короба» ($W+160$, $H+160$).
- **Шаблоны ячеек:** создание и сохранение собственных шаблонов с вечным хранением в `localStorage`.

### 4. Иерархические базы данных и Единый Менеджер БД (`DatabaseManagerModal.tsx`, `databaseService.ts`)
- **Многоуровневое дерево материалов (`defaultMaterialTree.ts`, `MaterialsTree.tsx`):**
  - Произвольная глубина вложенности папок:
    - `Лист`: *Сталь чёрная (С245, С255, С345, С390)*, *Сталь оцинкованная (0.55–2.0 мм)*, *Алюминий*, *Неметаллы*, *Иные металлы*, *Сталь нержавеющая*.
    - `Краска`: *Порошковые RAL 7012, 9005, 9006, 7021, цинковый грунт*.
    - `Профиль`: *Schueco*, *Alutech (EF100, EF100.40, F50, EF65...)*, *MacTex (Береговой, Резина)*, *inicial*, *Realit*.
    - `Стандартные профиля`: *Алюминиевые (трубы, уголки, полосы, прутки)*, *Стальные (квадратные/прямоугольные трубы, швеллеры, уголки, круги, двутавры)*, *ПНД*, *ПВХ*.
    - `Дерево` и `Декор`.
  - Каждый материал: Обозначение, Наименование, ГОСТ/Стандарт, ЕИ, Толщина, Вес.
  - **Двойная привязка:** назначение материала как несущего профиля или как комплектующего/уплотнителя (`EF100.1901`).
- **База метизов с динамической фильтрацией (338+ заводских позиций):**
  - Автоматическое извлечение типов из `Метизы.xlsx` (18 категорий: *Винт Самонарезной Alutech, Shueco, Болт, Винт, Гайка, Гайка-Барашек, Заклепка, Т-Гайка...*).
- **Привязка своих Excel-файлов по кнопке «📁 Выбрать»:**
  - Импорт любого файла `.xlsx` с авто-построением папок по путям.
  - Вечное сохранение в `localStorage`.

### 5. BOM-движок спецификаций («Модуль Жукова» / А1187 М507)
- 19 производственных колонок (A–S): Марка, Наименование, Материал (обозначение, кол-во, ЕИ), Шаблон техпроцесса, Тип связи, VGB-параметры ($L$, $B$, $LB$, цвет, углы подрезки VGP).
- Интерактивная живая таблица с фильтрацией по деталям и комплектующим.
- Экспорт в Excel (`.xlsx`) с цветной кодировкой строк:
  - Пастельный жёлтый (`#FFF2CC`) — строки сборочных единиц (кронштейны сварные/сборные, узлы).
  - Мягкий зелёный (`#E2EFDA`) — строки деталей каркаса.
  - Мягкий синий (`#D9E1F2`) — строки комплектующих и крепежа (поля `VGB_Plan_Group` и габариты остаются пустыми).

## 💻 Запуск из исходного кода (Для разработчиков)

### Требования:
- Node.js (версия 20 или 22+).
- Windows 10/11 x64.

### Установка и запуск:
```bash
# 1. Склонировать репозиторий
git clone https://github.com/pururuall/Spectool.git
cd Spectool

# 2. Установить зависимости
npm install

# 3. Запустить веб-версию (порт 3000)
npm run dev

# 4. Запустить настольную версию Electron
cmd /c "set ELECTRON_RUN_AS_NODE=& npx.cmd electron ."
```

### Сборка standalone `.exe` (Portable):
```bash
# Сборка фронтенда и упаковка в релизный Spectool.exe
npm run build
cmd /c "set ELECTRON_RUN_AS_NODE=& npx.cmd electron-builder --win portable"
```
Готовый файл создаётся в папке `release/Spectool.exe` (~109 МБ).
